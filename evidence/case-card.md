# Карточка кейса: «Кто выгуливает Бориса»

## Контекст

В учебном сценарии вымышленного офиса сотрудники договариваются, кто выгуляет Бориса. Без общей страницы сложно быстро увидеть свободное время и понять, кто уже записался.

## Задача

Сделать небольшую общую страницу, где сотрудник может выбрать свободный слот прогулки на сегодня и увидеть состояние записи. Дополнительно страница показывает последнюю отметку кормления.

## Гипотеза

Если показать только пять понятных слотов на текущую дату и их состояние, сотрудник сможет сам выбрать свободное время и зафиксировать запись без обращения к администратору.

## Решение

Локальное Node.js-приложение с общей страницей и SQLite-хранилищем. Для текущей даты показываются слоты 09:00, 11:00, 13:00, 15:00 и 17:00. Свободный слот можно занять, указав синтетическое ФИО. Сервер атомарно отклоняет повторную запись, сохраняя первоначального записавшегося. Отдельная небольшая форма позволяет отметить кормление; карточка показывает последнюю отметку.

## Результат проверки

По журналу в [PLAN.md](../PLAN.md), серверные проверки подтвердили создание пяти слотов, успешную запись, отказ при повторной записи без изменения исходного имени, сохранение записей в SQLite после перезапуска и обновление карточки кормления. Пользователь подтвердил читаемость на широком и узком экране, появление сообщения об отказе, отображение данных кормления и отсутствие ошибок в консоли браузера.

Эти пункты описывают выполненные проверки, зафиксированные в плане. Материалы для независимого просмотра проверяющим следует приложить отдельно:

- Семь скриншотов финальной версии: **ещё не приложены**.
- Короткое демо: **ещё не приложено**.
- След ключевой итерации с ИИ: **ещё не оформлен**.

## Границы

Это учебный micro-MVP, а не внутренняя система компании. Используются только синтетические данные. В проект не входят авторизация, роли, администрирование и отмена записей, уведомления, недельный календарь, история действий, внешние интеграции или обязательный деплой. Подробные границы приведены в [README.md](../README.md), требования — в [spec.md](../spec.md).

## Локальный запуск

Нужен Node.js 22.13.0 или новее. Из папки проекта выполните `npm start`, затем откройте `http://127.0.0.1:3000/`. Полная инструкция — в [README.md](../README.md).
